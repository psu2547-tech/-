가격 맞히기 실시간 수업 웹앱 — 배포·사용 안내

먼저 알아둘 점

이 파일은 인터넷에 이미 공개된 사이트가 아니라 **직접 배포할 수 있는 웹앱 소스**입니다. 아직 학생에게 안내할 공개 주소는 없습니다. HTML 파일만 열거나 Google Drive에 올리면 실시간 수업은 작동하지 않습니다. GitHub와 Render에서 아래 공개 단계를 진행해야 합니다. 비밀번호·로그인 정보는 AI에게 보내지 마세요.

원본 price.13w.kr 안내의 수업 흐름을 참고한 독립 구현입니다. 원본 코드·상품 사진·판매 화면·정확한 점수 공식·세부 디자인은 복사하지 않았습니다. 기본 문제 20개는 이모지와 연습용 가격이며, 교사가 사진과 가격을 수정할 수 있습니다. 따라서 원본의 완전한 복제본이 아닙니다.

1. 공개 주소 만들기 — GitHub + Render

1. 다운로드한 압축 파일을 풉니다.

2. https://github.com 에 가입 또는 로그인 → **New repository**. 이름은 원하는 대로 정하고 **Private** 권장 → **Create repository**.

3. 저장소에서 **uploading an existing file** 또는 **Add file → Upload files**를 선택합니다. 압축을 푼 폴더의 **내용 전체**를 올립니다. 최상위에 package.json, server.js, core.js, qr.js, render.yaml과 public 폴더가 있어야 합니다. ZIP 자체를 올리는 것이 아닙니다. **Commit changes**.

4. https://render.com 에 가입 또는 로그인 → **New → Web Service**. **Static Site가 아닙니다.** GitHub를 연결하고 방금 만든 저장소를 선택합니다. 비공개 저장소 접근은 필요한 저장소만 허용하세요.

5. 아래 설정을 입력합니다.

- Language / Runtime: Node

- Branch: 기본 브랜치(보통 main)

- Root Directory: 비워 둠

- Build Command: `npm install && npm test`

- Start Command: `npm start`

- Instance Type: **Free** (무료 항목을 직접 확인)

- Environment Variable 이름: `TEACHER_PIN`

- Environment Variable 값: **선생님이 정한 길고 고유한 비밀번호**. 학생에게 공유하지 마세요. 설정하지 않으면 방을 만들 수 없습니다.

6. **Deploy Web Service** 또는 **Create Web Service**를 누릅니다.

7. 배포 화면에 표시되는 **실제 서비스 주소**를 엽니다. 이 주소는 Render가 배포 성공 뒤 발급합니다. 안내문에 실제 주소가 없는 것은 아직 배포하지 않았기 때문입니다.

8. 첫 화면 아래 **선생님 화면 열기**를 누릅니다. 설정한 교사 비밀번호를 입력하고 수업 방을 만듭니다. 교사 화면 경로는 `/tv`입니다.

9. TV의 **학생 주소 복사** 또는 **접속 QR**를 학생에게 안내합니다. 학생은 태블릿 브라우저에서 접속하고 번호·별명을 입력하면 됩니다. 학생은 Render·GitHub 계정이 필요 없습니다.

학생에게는 교사 화면이나 GitHub·Render 관리 페이지가 아니라, **방 화면에 실제로 표시되는 학생 주소**만 전달합니다. Render가 제공하는 HTTPS를 사용하세요.

무료 플랜의 선택 가능 여부·정책·본인 확인 요구는 서비스 운영자가 결정합니다. 요금 또는 결제 수단 화면이 나오면 무료 플랜과 사용 한도를 확인하고 원하지 않는 결제는 진행하지 마세요.

2. 학교에서 접속 확인 — 반드시 수업 전에

원본 주소가 차단됐다고 해서 새 주소가 자동으로 허용되지는 않습니다. 차단 원인도 아직 확인되지 않았습니다. GitHub 또는 Render의 관리 페이지가 열린다고 배포된 수업 주소도 열린다는 뜻은 아닙니다.

1. 학교 Wi-Fi의 교사 PC와 학생 태블릿으로 **배포된 실제 수업 주소**에 접속합니다.

2. 방 생성 → 태블릿 2대 이상 입장 → 첫 답안 제출 → 마감 → 가격 공개까지 확인합니다.

3. 접속이 안 되면 학교 정보 담당자에게 이 수업 주소의 접속 허용 여부를 확인해 주세요. 승인된 학교 서버가 있다면 이 Node.js 앱을 그곳에 설치할 수 있습니다. 우회 접속이나 보안 설정 해제는 권하지 않습니다.

4. 이 앱의 기본 기능은 하나의 배포 주소만 사용합니다. 원본 서버·Firebase·외부 QR API·CDN 글꼴에 연결하지 않습니다. 교사 PC와 태블릿이 서로 직접 연결될 필요도 없습니다.

3. 수업 운영

- 교사 비밀번호 입력 → 제한 시간, 영어/숫자 입력, 문장 선택, 자동 마감 설정.

- 기본 20문제를 그대로 사용하거나 **문제 세트 편집**에서 물건 이름·가격·It is/They are·사진 변경. 실제 수량이 보이는 직접 촬영 사진을 권장합니다. 이모지 기본 그림은 물건 종류를 상징하므로 수량은 이름으로도 안내합니다.

- **내 문제 저장**으로 JSON 백업, 다음 수업에서 **내 문제 불러오기**.

- 방 만들기 → QR/주소로 학생 입장 → 시작.

- 학생: It is 또는 They are 선택 → 화면 키보드로 가격 입력 → 제출. 마감 전에는 고칠 수 있음.

- 교사: 제한 시간 종료 / 모두 제출 / 직접 마감 → 예측 가격 보기 → 가격 공개 → 다음 문제.

- 시상식에서 전체 순위·공동 순위·Perfect 왕·문장 박사·번개손·가격 감각상 확인, 결과 CSV 다운로드.

- 마지막에 **방 삭제**를 눌러 기록 삭제.

학생 화면은 약 1.1초마다 동기화됩니다. 방은 최대 60명, 문제는 최대 40개입니다. 사진은 교사 화면에만 전송됩니다. 모든 학생의 제출 여부만 교사에게 보이며, 입력 중인 답과 정답 가격은 공개 전 학생에게 전송하지 않습니다. 학생들은 가격 공개 후 전체 순위에서 별명과 점수를 볼 수 있습니다.

재접속

같은 태블릿·같은 브라우저에서 같은 방 주소로 돌아오면 저장된 임의 접속 키로 이어집니다. 브라우저 데이터 삭제·시크릿 창·다른 기기에서는 같은 이름만으로 복구할 수 없습니다. 이름 도용 방지를 위해 새 별명으로 입장해야 합니다. 교사 화면은 **같은 탭에서 새로고침**하면 복구됩니다. 교사 탭을 닫으면 교사 제어 키를 잃을 수 있으므로 수업 중 닫지 마세요. 이 앱에는 관리자 복구 기능이 없습니다.

점수 — 이 구현의 자체 기준

가격 기본점수 = 반올림(100 × (1 − min(|예측 − 정답| / 정답, 1))).

정확히 맞힘: +50점. 5% 이내(정확히 맞힌 경우 제외): +20점.

문장 선택 기능 사용 시 It is / They are 정답: +10점.

최대 160점. 가격만 쓰기에서는 최대 150점. 미제출 0점. 점수와 Perfect 수가 모두 같으면 공동 등수입니다.

영어 입력

1~999,999원 정수 지원. 예: `eleven thousand three hundred`. 하이픈, 일부 and 표현, 끝의 won 허용. 기본 모드에서는 숫자 입력을 거절합니다. 영어로만 입력하는 연습을 위해 자동 완성이 없는 자체 키보드가 기본입니다. 기기 키보드를 선택하면 운영체제의 자동 완성이 작동할 수 있습니다.

음성인식은 선택 사항이며 지원되는 브라우저에서만 작동합니다. 처음 사용하기 전에 전송 가능성을 안내하는 확인 창이 뜹니다. 목소리가 Google·Apple 등 브라우저 제공업체로 전송될 수 있습니다. 학교 개인정보·미성년자 관련 지침을 확인하세요. 학교망이나 기기 정책으로 막힐 수 있습니다. 핵심 기능은 음성인식 없이 작동합니다. 정답 문장 듣기도 브라우저 음성합성 지원에 따라 달라집니다.

4. 개인정보·운영 제한

- 학생 실명 대신 번호나 별명만 사용. 학생 로그인·이메일·전화번호·생년월일 불필요.

- 방·사진·별명·답안·점수는 서버의 메모리에만 임시 저장. 서버 재시작·배포·중단 때 기록이 사라집니다. **영구 보관용 시스템이 아닙니다.** 교사가 90분 동안 진행 조작을 하지 않으면 방이 만료됩니다. 방 삭제 시 해당 기록을 삭제합니다.

- 서버가 접속 처리를 위해 IP 등을 다룰 수 있고, 호스팅 업체의 로그·국외 처리 정책은 별도입니다. 수업 전 학교 정책을 확인하세요.

- 교사가 다운로드한 결과 CSV·문제 JSON은 기기에 남으므로 필요 기간 후 직접 삭제하세요. 개인 정보가 담긴 사진을 업로드하지 마세요.

- 교사 비밀번호와 방 제어 키는 공유하지 마세요. 방 번호도 해당 수업 학생에게만 안내하세요. 학생 등록은 방 번호를 아는 사람에게 개방되어 있으므로 고위험·민감 정보 처리에 사용하지 마세요.

- 여러 서버 인스턴스에 걸쳐 운영하거나 자동 확장하면 안 됩니다. 단일 Node 프로세스용입니다. 대규모 사용에는 DB, 모니터링, 보안 점검 등이 추가로 필요합니다.

- 기기 절전·인터넷 불안정·호스팅 재시작으로 수업이 끊길 수 있으므로 첫 수업 전에 소규모 시험이 필요합니다.

5. Render 무료 운영 주의

공식 문서 기준, Free Web Service는 15분 동안 수신 요청이 없으면 중지되고 다음 접속 때 다시 시작하는 데 약 1분이 걸릴 수 있습니다. 무료 사용량 제한과 재시작 가능성이 있습니다. 수업 몇 분 전에 주소를 열어 준비하세요. 중지·재시작하면 메모리 속 수업은 없어지므로 **매 수업 새 방**을 만드세요. 유료 결제 없이 쓰려면 Free 선택과 관리 화면 사용량을 확인하세요.

공식 안내: https://render.com/docs/free

배포 안내: https://render.com/docs/deploy-node-express-app

6. 학교 담당자·개발자용

Node.js 20 이상 권장(현재 LTS 권장). 외부 npm 의존성 없음. 실행 전에 TEACHER_PIN 환경 변수 설정. `npm start`, 오프라인 자동 테스트 `npm test`. 운영 서비스는 HTTPS 역방향 프록시 뒤에서 사용. PORT 환경 변수 지원, 0.0.0.0 바인딩. `/health` 점검 경로. 상세 파일: server.js HTTP 계층, core.js 게임·권한·채점, qr.js 자체 QR 인코더, public/ 화면.

Windows PowerShell 로컬 실행 예:

$env:TEACHER_PIN="여기에-직접-정한-비밀번호"
npm start

macOS / Linux 로컬 실행 예:

TEACHER_PIN='여기에-직접-정한-비밀번호' npm start

로컬 테스트 주소는 http://localhost:3000 입니다. **학생에게 localhost 주소를 안내하면 안 됩니다.** 이는 교사 자신의 컴퓨터만 가리킵니다. 인터넷 공개는 앞의 배포 절차로 진행합니다.

보안 기초: 교사 전용 비밀번호, 192비트 임의 방/학생 제어 키, 학생 권한 검증, 정답 공개 전 비노출, 동일 출처 API, CSP, HTML 이스케이프, 파일 경로 허용목록, 업로드 제한, 기본 요청 빈도 제한, CSV 수식 삽입 완화. 별도 외부 보안 감사를 받은 제품은 아닙니다.

QR은 이 앱 자체 서버에서 생성하며 외부 서비스에 주소를 보내지 않습니다. 고정 QR Version 5-L을 사용하여 UTF-8 106바이트 이내 주소를 지원합니다. 주소가 그보다 길면 QR 대신 학생 주소를 복사해 안내하세요.

검증 범위

제작 환경에 Node.js가 없어 서버 실행·실제 브라우저·학교 태블릿 테스트는 수행하지 못했습니다. 정적 구성은 확인했고 자동 테스트 코드를 동봉했습니다. 배포 Build Command의 npm install && npm test가 배포 서버에서 검사를 실행합니다. 배포 성공 후 소규모 수업 시험을 진행하세요. 아직 공개 접속 주소는 없습니다.
